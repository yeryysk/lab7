ВИСНОВКИ:

Під час виконання практичної роботи №7 було досліджено структуру циклічного зв'язаного списку та його застосування в алгоритмах планування. 

1. Аналіз симуляції Round-Robin:
Було реалізовано симуляцію розподілу процесорного часу між процесами з фіксованим квантом часу. Черга процесів реалізована у вигляді циклічного списку, де хвіст (tail) посилається на голову. Це дозволяє алгоритму працювати за принципом FIFO (First-In-First-Out) з нескінченним циклом перебору. Якщо процес не завершився за відведений квант, він повертається в кінець черги. Часова складність переходу до наступного процесу — O(1).

2. Виконання індивідуального завдання (Варіант 1):
Задачу Йосипа Флавія було успішно розв'язано за допомогою циклічного списку. Алгоритм імітує процес виключення кожного k-го елемента до тих пір, поки в списку не залишиться один вузол. Використання циклічного списку дозволило уникнути зайвих перевірок на кінець масиву, роблячи процес видалення вузла максимально ефективним (O(1) для безпосереднього видалення, якщо відомий вузол).

ПЕРЕВАГИ ЦИКЛІЧНИХ СТРУКТУР:
- Відсутність необхідності обробляти "кінець" списку (оскільки список замкнений).
- Висока ефективність при операціях додавання/видалення елементів у черзі.
- Ідеальне рішення для задач, де елементи обробляються по колу (Round-Robin, маршрутизація, ігри).

СКЛАДНІСТЬ BIG-O:
- Додавання в кінець черги: O(1).
- Отримання наступного елемента: O(1).
- Видалення завершеного процесу: O(1).
Загальна складність симуляції для N процесів із загальним часом T: O(N * T), де кожен крок виконується за константний час.
